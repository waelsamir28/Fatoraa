# FATORA - نسخة الويندوز (EXE)

هذا المجلد يحوّل **FATORA** إلى برنامج ويندوز كامل:

- ✅ ملف تثبيت `Fatora-Setup-1.0.0.exe` + نسخة محمولة `Fatora-Portable-1.0.0.exe`
- ✅ يعمل **بدون إنترنت** وبدون تثبيت أي قاعدة بيانات (قاعدة بيانات مدمجة داخل البرنامج)
- ✅ نافذة بدون إطار تستخدم شريط العنوان الأزرق الخاص بالبرنامج (تصغير / تكبير / إغلاق)
- ✅ كل الشاشات تفتح كاملة على الشاشة (ملء الشاشة تلقائياً على أي مقاس)
- ✅ اختصار على سطح المكتب وقائمة ابدأ باسم "FATORA"
- ✅ البيانات تُحفظ في: `%APPDATA%\FatoraPOS\database`

---

## الطريقة 1 (الأسهل): بناء تلقائي على GitHub

1. ارفع المشروع على GitHub.
2. افتح تبويب **Actions** ← **Build Windows EXE** ← **Run workflow** (ويعمل تلقائياً مع كل push).
3. بعد انتهاء البناء (حوالي 10 دقائق) حمّل الملف من **Artifacts** باسم `Fatora-Windows-EXE`.
4. عند عمل tag مثل `v1.0.0` يتم إنشاء Release فيه ملفات الـ exe مباشرة.

## الطريقة 2: البناء على جهازك (ويندوز)

1. ثبّت **Node.js** (نسخة 20 أو أحدث) من https://nodejs.org
2. افتح موجه الأوامر (CMD) داخل مجلد المشروع ونفّذ:

```bat
npm install
cd desktop
npm install
npm run dist
```

3. ستجد الملفات داخل `desktop\dist`:
   - `Fatora-Setup-1.0.0.exe` ← ملف التثبيت (موصى به)
   - `Fatora-Portable-1.0.0.exe` ← نسخة تعمل بدون تثبيت

> للتجربة السريعة بدون عمل ملف تثبيت: `npm start` داخل مجلد `desktop`.
